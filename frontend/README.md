# Enterprise KB Agent — Frontend

Next.js (App Router, TypeScript) client for the Enterprise KB Agent: a product showcase page (`/`)
and a streaming chat interface with voice input and output (`/chat`).

```bash
npm install
cp .env.local.example .env.local   # set NEXT_PUBLIC_API_BASE_URL
npm run dev
```

See the [project README](../README.md) for architecture, API reference and deployment details.
